# Results: weighting and reranking (step 4)

Generated by `scripts/run_rerank.py`. Earlier steps: [keyword search](results.md), [vector and hybrid search](results-vector-hybrid.md).

## Setup
- **First search:** keyword (BM25) and vector top 100 lists, fused with reciprocal rank fusion (k = 60). The vector list's weight was chosen from 1, 1.5, 2, 3 on CSF 2.0 dev questions by MRR.
- **Reranking:** the top 30 of the fused list are rescored by a cross-encoder that reads the question together with each control's title and statement (cut at 512 tokens). On test questions, these 30 candidates hold 53.2% of CSF 2.0's right controls and 97.8% of SP 800-171's, which is as far as reranking can go.
- **Models tried** (on this computer's CPU, at pinned versions): cross-encoder/ms-marco-MiniLM-L6-v2 (Apache-2.0); mixedbread-ai/mxbai-rerank-xsmall-v1 (Apache-2.0); BAAI/bge-reranker-base (MIT). The best on CSF 2.0 dev questions by MRR was then run once on the test questions.
