# Results: searching with the question in NIST's words

Generated by `scripts/run_rewrite.py`. Don't edit by hand.

qwen3:8b rewrites each question as 3 short search queries in SP 800-53's words, and can search again with 1 more query after reading the titles of the top 5 results (`src/controlfinder/rewrite.py`). Each query is searched by keyword and by meaning (nomic-embed-text), and every list is fused with the question's own (weighted reciprocal rank fusion, as in step 4). Every reply and every query's vector results are kept in `results/rewrite_answers.json`, so the scores are recomputed without a model.
